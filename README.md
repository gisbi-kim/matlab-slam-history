# MATLAB SLAM History

SLAM을 공부하는 학생과 연구자를 위한 한국어 가이드입니다. 연구 논문의 발표 시점과 MATLAB API의 도입 시점을 구분하고, 두 사건의 대응을 탐색합니다.

- [사이트](https://gisbi-kim.github.io/matlab-slam-history/)
- [논문 ↔ 릴리즈 가로 연결 지도](https://gisbi-kim.github.io/matlab-slam-history/#connections)

## 두 가지 보기

- **세로 역사 연표:** 공통 연도 축에 논문과 MATLAB 릴리즈를 나란히 배치합니다. 논문·저자·함수 검색, 분야·시대 필터, 정렬과 개별 연구 계보를 제공합니다.
- **가로 대응 지도:** 논문별 행에서 발표 지점과 대응 API 릴리즈를 연결합니다. 시간 비례 가로축, 2008년 이후 확대/전체 범위, 관계 필터, 연결별 근거 패널을 제공합니다.

현재 자료에는 문헌 14편, MATLAB 주요 변경 31개, 논문–릴리즈 연결 22개가 있습니다. 세 가지 학습 경로와 항목별 질문도 제공합니다.

## 근거와 한계

2026-10-11 확인 자료를 바탕으로 작성했습니다. MathWorks 공식 함수 문서의 Version History와 References, 과거 발표 자료, 논문 원문 및 출판사 자료를 연결합니다. 사이트의 각 항목에서 출처를 열 수 있습니다.

- **공식 문서 인용:** 해당 API 문서의 참고문헌에서 확인한 대응입니다. 원 논문의 코드나 시스템 전체를 그대로 구현했다는 의미는 아닙니다.
- **후속 API 변화:** 동일 기능의 객체화, 확장 또는 제품 이동입니다.
- **배경 읽기:** 개념을 이해하기 위한 연결이며 직접 구현 근거가 아닙니다.
- **릴리즈 추가 확인:** 제공된 초안 기반으로, 역사적 도입 시점의 추가 대조가 필요한 항목입니다.

논문 출판 연도와 MATLAB 릴리즈 연도를 별도 사건으로 표시합니다. 학회판/저널판 연도 차이는 문헌별 주석을 참고하세요. 세로 연표의 간격은 시간 비례가 아니며, 가로 지도에서는 확대 범위 이전 논문을 경계에 표시합니다. 일부 주요 변화만 선별했으며 전체 SLAM 연구사 또는 전체 릴리즈 기록을 망라하지 않습니다. MATLAB 코드 실행 검증은 수행하지 않았습니다. MathWorks 공식 사이트가 아닙니다.

## 로컬 실행

Python 3가 설치된 환경에서 저장소 루트에서 실행합니다.

```text
python -m http.server 18943 --bind 127.0.0.1 --directory dist
```

브라우저에서 `http://127.0.0.1:18943/`를 엽니다. Windows에서는 `powershell -ExecutionPolicy Bypass -File .\start.ps1`도 사용할 수 있습니다. 종료는 Ctrl+C입니다. 빌드나 패키지 설치는 필요하지 않습니다.

## 구조와 수정

| 파일 | 역할 |
| --- | --- |
| `dist/index.html` | 페이지와 학습 경로 |
| `dist/data.js` | 릴리즈, API, 출처, 확인 상태 |
| `dist/papers.js` | 문헌과 22개 대응 관계 |
| `dist/app.js` | 세로 연표 검색·필터·계보 |
| `dist/connections.js` | 가로 대응 지도와 탭 |
| `dist/*.css` | 기본·세로 연표·가로 지도 스타일 |
| `.github/workflows/pages.yml` | JavaScript 구문 검사 후 Pages 배포 |

내용 변경은 데이터 파일에서 진행합니다. 출처와 인용/후속/배경 구분을 함께 갱신하고, 연결의 릴리즈 및 API가 실제 데이터에 존재하는지 점검합니다. `main`에 push하면 `dist/`만 GitHub Pages에 배포합니다.

## 검증 및 공개 범위

2026-10-11 로컬 브라우저에서 검색, 필터, 정렬, 검색 결과 없음, 개별 계보, 연결 끝점 선택, 공식 인용 필터, 탭 전환과 세로 연표의 390px 모바일 레이아웃을 확인했습니다. JavaScript 구문 검사와 22개 연결 대상의 존재 검사를 통과했습니다.

정적 HTML/CSS/JavaScript만 제공하며 별도 서버, 계정, 분석 스크립트 또는 사용자 입력 저장 기능은 없습니다. 논문은 링크로 제공하고 원문 파일을 복제하지 않습니다. 공개 저장소에는 사이트 소스와 배포 설정만 포함하며 원 대화·첨부파일·로컬 설정은 포함하지 않습니다.
